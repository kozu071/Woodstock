Una página de música para comprar vinilos, CDs, cassettes y diferentes mercaderias de bandas y artistas de más que nada rock de epocas variadas.

En busquedas por páginas como esta, se encontró que casi no existen y que las pocas que hay, no estan actualizadas y tienen muy poca variedad. El objetivo de esta página, es ser una manera más fácil de comprar y ver música a la venta sin tener que salir de la casa. Pensada para usuarios coleccionistas de música y hecha de manera que sea fácil de utilizar y de entender lo visto, sabiendo que muchos usuarios podrían ser mayores.

La página usa más que nada HTML mezclado con bastante JavaScript y CSS (47.3%, 31%, 21.7%).

Dentro de la página, se ve una carpeta que tiene el archivo .css, una carpeta que tiene los archivos .html (index, busqueda, carrito, cassettes, cds, favoritos, mercaderia, ofertas, producto y vinilos), una carpeta con imagenes generales con 5 carpetas dentro representando cada tipo de producto, cada una con 9 imagenes, una carpeta con el archivo .js y por último, el archivo README.

La página fue hecha con el editor de codigo Visual Studio Code, utilizando como ayuda el widget de Live Preview y la IA Copilot, siendo un estilo de escritura de code vibing.

Con la página, aprendí sobre IAs y como usarlas mejor para ayudar en proyectos y al mismo tiempo ser independiente. Me ayudó a aprender más sobre los lenguajes usados por la parte del backend y sobre como debe quedar bien para atraer más usuarios la parte del frontend.

Al no tener un servidor disponible en donde guardar la información almacenada, no ah sido posible agregar una sección en donde poder iniciar sesión o registrarse y ver su porpia cuenta. Es por esto que otras secciones que la página sí tiene, como favoritos o carrito, solo funcionan mientras uno no cierre la pestaña, ya que luego se perderá todo.

Una proxima mejora a realizar, será la función de tener cuenta propia guardada en un servidor. No solo se arreglará lo mencionado anteriormente, sino que dará camino a la posibilidad de poder vender productos uno mismo en esta, volviendose una página de compra y venta y no solo de compra.
